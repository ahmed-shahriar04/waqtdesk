⚡ Overview

WaqtDesk is a lightweight desktop prayer times widget built with Rainmeter and powered by an event-driven Lua engine.

Designed for simplicity and convenience, WaqtDesk keeps your daily prayer schedule accessible without interrupting your workflow.

From live prayer countdowns to dynamic Sun and Moon visualizations, everything you need is presented in a clean, compact desktop interface.

Installation Steps
Install Rainmeter if it is not already installed.
Open the WaqtDesk v3.5.0 Release Page.
Scroll down to the Assets section and download the .rmskin installer.
Double-click the downloaded file to launch the Rainmeter Skin Installer.
Follow the on-screen instructions to complete the installation.
Open Rainmeter Manager and load WaqtDesk.ini if the skin is not loaded automatically.
