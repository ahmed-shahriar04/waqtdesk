⚡ Overview

WaqtDesk is a modern desktop prayer times widget built on Rainmeter and powered by a high-performance, event-driven Lua engine. It provides a distraction-free desktop experience, tracking prayer schedules with live countdowns, dynamic Sun and Moon visualizations, and essential daily solar information at a glance.

✨ Features
🌌 Modern Desktop UI: A deep emerald interface designed to complement Windows 11 workspaces.
⏱️ Live Prayer Countdown: Second-by-second countdown to upcoming prayer times.
☀️ Dynamic Celestial View: Real-time Sun and Moon movement throughout the day.
🎛️ Solar Information Chips: Quick access to Sunrise, Sunset, Sahri end time, and Iftar.
⚙️ Built-in Settings Panel: Configure preferences directly from the widget.
Madhab Selection: Switch between Hanafi and Shafi'i / Standard Asr calculation methods.
Bilingual Interface: Switch between English and বাংলা (Bengali).
Smart Geolocation: Automatic IP-based location detection or manually configured coordinates.
🛡️ Lightweight Performance: Event-driven Lua execution designed to minimize CPU usage.

📥 Installation
Prerequisites
Windows
Rainmeter 4.5 or newer
A Bengali font, such as Kalpurush, Hind Siliguri, or SolaimanLipi, for optimal Bengali text rendering.
Download & Install
Visit the WaqtDesk v3.5.0 Release Page.
Scroll down to the Assets section.
Download the WaqtDesk .rmskin installer.
Double-click the downloaded .rmskin file to open the Rainmeter Skin Installer.
Follow the installation prompts to install WaqtDesk.
Open Rainmeter Manager and load WaqtDesk.ini if it is not loaded automatically.
⚙️ Settings & Customization

Click the ⚙ gear icon in the top-right corner of the expanded widget to access the settings panel.

Parameter	Options	Description
School (Madhab)	Hanafi / Shafi'i	Selects the Asr prayer calculation method.
Language	English / বাংলা	Changes interface labels, prayer names, and dates.
Location	Auto IP / Manual	Detects your approximate location automatically or accepts custom latitude and longitude coordinates.
